# Schema Design Checklist

## Schema Design Checklist

1. Identify entities from the problem statement.
2. List attributes for each entity.
3. Identify relationships between entities.
4. Determine cardinality of each relationship.
5. Place foreign keys (on the many side of 1:N).
6. Resolve many-to-many relationships using junction tables.
7. Check normalization (1NF, 2NF, 3NF).
